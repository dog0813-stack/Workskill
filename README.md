# Workskill

## OA 费用报销技能

把下面一句话复制到 Codex：

```text
请使用 skill-installer 安装 https://github.com/dog0813-stack/Workskill/tree/main/skills/oa-expense-reimbursement
```

安装成功后，在下一轮对话使用：

```text
使用 $oa-expense-reimbursement，整理这些票据并填写我的 OA 报销草稿。先核对已有草稿、费用与关联申请，保存后给我确认，暂不提交。
```

需要 Codex 中可用的浏览器工具、你自己的 OA 登录权限、本人授权的票据和公司报销要求。技能不自带浏览器或邮箱连接，也不会自动登录或绕过验证码。

支持票据核对、关联申请、附件整理上传、草稿保存和确认后的提交。不新建或修改出差、公车使用申请；首次使用先验证草稿，再由本人确认最终提交。

本仓库只包含脱敏流程，不含账号、银行卡、真实票据或公司专属网址。尚未在接收者 OA 上端到端测试；不保证审核通过或付款。
