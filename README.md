# Workskill

## OA 费用报销技能

让员工在自己的 Codex 和已登录的邮箱/OA 中，用一句话发起报销；优先用授权的邮箱连接查票，用 Chrome 插件下载站外票据、核对并填写 OA、关联已有申请、上传附件、保存草稿，并在本次有效授权和工具权限允许时提交、核验申请单号。

本仓库保留原技能名称 `oa-expense-reimbursement`。共用流程，各员工使用自己的身份、配置、会话和记录；不需要先开发独立网页。

### 安装或更新

把下面一句话交给 Codex：

```text
请检查是否已安装 oa-expense-reimbursement。未安装时使用 skill-installer 安装 https://github.com/dog0813-stack/Workskill/tree/main/skills/oa-expense-reimbursement；已安装时先检查本地定制并保留，再更新这个已有技能。不要把我的账号、票据或任务记录放进共享技能目录。
```

查看安装结果后，在技能选择器里选择“OA 费用报销”，或在支持的 Codex 输入框中使用 `$oa-expense-reimbursement`。

### 使用示例

```text
使用 $oa-expense-reimbursement，帮我报销 9 月 21 日出差的停车费和过路费。发票在我已登录的企业邮箱里，请找齐材料，关联已有出差和公车申请，核对后提交。缺少影响报销的信息时，只问具体缺项。
```

先做草稿：

```text
使用 $oa-expense-reimbursement，整理本次购买材料的票据，填写并保存我的 OA 报销草稿，暂不提交。
```

中断后继续：

```text
使用 $oa-expense-reimbursement，先读取我上次这笔报销的任务记录，再核对 OA 实际状态，从未完成步骤继续；提交结果不明确时先查询。
```

### 首次准备

- Gmail 邮件和附件走 Gmail 连接，票据站外链接与 OA 走已连接的 Chrome 插件。企业邮箱可复用已有授权的连接。只有用户允许且确有桌面步骤时才启用 Computer Use。
- 员工本人登录邮箱和 OA，按工具提示授予所需访问；登录失效、验证码和客户端要求的确认仍可能需要本人处理。
- 将技能中的 `assets/employee-profile.example.json` 复制到员工自己的私有目录并填写必要信息。私有目录须在所有 Git 工作树和共享技能目录之外；不在配置中保存密码、令牌或银行账号。
- 本机状态助手使用 Python 3.10+ 标准库。其作用是记录进度、恢复任务和阻止状态不明时再次进入提交步骤；实际界面动作仍由 Codex 调用控制工具完成。
- 云电脑运行时确认工具能控制那台云电脑。Windows 原生桌面控制会使用活动前台，运行期间不要同时操作同一桌面；断开或锁屏后的行为需实测。
- 先用本人一笔真实任务校准字段和制度，再让一名员工使用独立账号复现，之后扩大范围。

配置、工具选择和命令详见技能内的 [电脑操作与任务记录](skills/oa-expense-reimbursement/references/computer-use.md)。

### 验收标准与当前边界

草稿交付以重新打开原待发单后的核对结果为准，检查必填项、期间、金额、关联和附件。本人手动发送后，只有查到 OA 实际单号和状态才能确认提交。审批与付款按公司流程继续。

不新建或修改出差、公车使用申请；只关联已有匹配记录。保留必要的本人授权和工具确认，不能绕过安全或权限要求。

仓库只包含脱敏流程、配置示例、状态助手和离线测试，不包含账号、真实票据、公司专属网址或员工记录。新增流程仍须在接收员工实际环境完成端到端验收；不保证所有 OA 页面已适配、审核通过或付款。任务节点的存档动作已写入技能，本仓库没有安装 Codex 原生 hook。
